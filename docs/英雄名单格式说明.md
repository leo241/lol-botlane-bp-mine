# 英雄名单格式说明

个人名单放在 `data/lists/` 下的 4 个 txt 文件里，用记事本就能改：

| 文件 | 作用 |
|---|---|
| `adc_blocklist.txt` | 下路(ADC) 不推荐名单 —— 名单内英雄不参与推荐、不占推荐名额 |
| `adc_favorites.txt` | 下路(ADC) 经常使用名单 —— 被推荐时页面用金色 ★ 标记 |
| `support_blocklist.txt` | 辅助 不推荐名单 |
| `support_favorites.txt` | 辅助 经常使用名单 |

## 写法规则

每行一个英雄，下面这些写法**都能识别**（大小写随意，空格自动忽略）：

```
凯特琳          ← 常用叫法 / 别名
皮城女警        ← 称号
Caitlyn        ← 英文名
caitlyn        ← 小写 key
51             ← 数字 ID
```

- `#` 开头是注释，空行忽略
- 写错的行不会报错，但不会生效（页面控制台和 `/api/mylists` 接口会提示哪些行没识别出来）
- 改完立即生效，不用重启服务

## 快速示例

假设你 ADC 只想玩金克丝和泽丽，讨厌寒冰和伊泽瑞尔，`data/lists/adc_favorites.txt` 写：

```
金克丝
Zeri
```

`data/lists/adc_blocklist.txt` 写：

```
寒冰
伊泽瑞尔
```

辅助只玩璐璐、锤石，讨厌猫咪，`data/lists/support_favorites.txt` 写：

```
璐璐
Thresh
```

`data/lists/support_blocklist.txt` 写：

```
猫咪
```

## 也可以在页面上直接操作

- 推荐结果表格里英雄名前面的 **★** 可以点击，加入/移出"经常使用名单"
- "英雄排除"按钮打开的弹窗里添加/移除的英雄，会自动保存到当前角色的"不推荐名单"文件
